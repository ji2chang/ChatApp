# Chat App

Una semplice applicazione di chat realizzata in Python utilizzando `socket` e `threading`.

## Caratteristiche
- Comunicazione in tempo reale tra client e server.
- Supporta più client connessi simultaneamente.
- Facile da configurare ed eseguire.

## Prerequisiti
- Python 3.11+

## Installazione
1. Clona il repository:
   ```bash
   git clone https://github.com/tuo-utente/chat-app.git
   cd chat-app
2. Esegui setup_venv.bat
3. Esegui run-client.bat
